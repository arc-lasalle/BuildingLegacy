# Building Legacy – Research Materials and Software

## Overview

This repository provides research materials and software developed within the Building Legacy project to support the documentation, evaluation, and reuse of building components.

It accompanies an associated scientific study and provides access to the materials supporting the transparency and traceability of the proposed reusable component data model, its operationalisation, and its application to a real building case study.

The repository includes:

- The parameter mapping and evaluation used in the derivation of the reusable component data model
- Component data sheets used during the research process
- A representative individual component data sheet template generated by the Building Legacy platform
- The source code of a Revit Add-in developed to support semi-automated acquisition of component information from BIM models

## Research Materials

### 1. Parameter Mapping and Evaluation

Location:

    data/parameter_mapping/

This folder contains the mapping and evaluation of candidate parameters used in the derivation of the Building Legacy reusable component data model.

The initial parameter structure was primarily informed by the BAMB (Buildings As Material Banks) framework and subsequently adapted to the documentation requirements and information conditions associated with reusable components from existing buildings.

Candidate parameters were assessed according to two criteria:

- **Availability (A1–A5):** the expected accessibility and reliability of the information required to document the parameter
- **Eligibility (E1–E5):** the relevance of the parameter for supporting the identification, assessment, and potential reuse of building components

The combination of these criteria supports the classification of parameters into four selection classes (S1–S4), which determine their incorporation and treatment within the resulting reusable component data model.

The complete derivation procedure, evaluation criteria, scoring scales, and selection rules are described in the associated scientific article.

### 2. Component Data Sheets

Location:

    data/component_sheets/

This folder contains the component data sheets developed during the research process for the six component categories considered in the study:

- Fire doors
- Metal structure pillars
- Glasses
- Tarpaulins
- Rev-A2A heat pumps
- Steel roll-up shutters

The component data sheets were used as research instruments to organise and refine the parameter structures associated with the different component categories. They distinguish between common parameters and component-specific parameters and document the resulting information requirements used to define the reusable component data model.

The six component categories were subsequently represented in the case study conducted at the Abaceria Central Market in Barcelona.

### 3. Individual Component Data Sheet Template

Location:

    data/templates/

This folder contains a representative example of an individual component data sheet template generated by the Building Legacy platform:

    Plantilla_puerta_contraincendios.xlsx

Individual component data sheet templates provide an operational representation of the parameter structure defined for each component type in the Building Legacy platform. They are intended to be populated with information describing an individual reusable component and subsequently uploaded to the platform to create or update its component record.

The template contains six fields for each parameter:

| Field | Description |
| --- | --- |
| Parameter name | Name of the parameter |
| Parameter value | Value to be provided for the individual component |
| Unit type | Unit associated with the parameter, where applicable |
| Data format | Expected data format (e.g., text, integer, decimal, selection or list) |
| Example value | Example provided to assist data entry |
| Mandatory | Indicates whether the parameter is required |

The fire-door template is provided as a representative example of the individual component data sheet templates used by the platform.

## Software – Revit Add-in

Location:

    software/revit_addin/

The repository includes the source code of a Revit Add-in developed as part of the research to support semi-automated acquisition of component information from BIM models.

The Add-in operates on an individual component data sheet template downloaded from the Building Legacy platform. After the user selects the corresponding component type and BIM elements, the tool retrieves parameter values available in the Revit model and transfers them to the corresponding fields of the Excel template.

The mechanism is intended to reduce manual data entry by reusing information already represented in the BIM model. Information that is not available through BIM can be incorporated into the same template from complementary sources.

### Main Features

- Selection of supported component types
- Identification and selection of corresponding BIM elements
- Import of individual component data sheet templates
- Semi-automated extraction of available parameter values from Revit
- Transfer of extracted values to the corresponding template fields
- Preservation of previously populated values not replaced through BIM extraction
- Export of the resulting individual component data sheet in Excel format

### Requirements

- Autodesk Revit 2026
- Compatible .NET environment
- Microsoft Excel-compatible `.xlsx` template

### Installation

Detailed installation and usage instructions are available in:

    software/revit_addin/

### Current Scope

The current implementation supports the component types addressed in the research and extracts the subset of parameters for which corresponding information can be retrieved from the Revit model.

The availability and quality of the extracted information therefore depend on the information represented in the BIM model. Parameters that are not represented or cannot be retrieved through the Revit API must be documented from complementary information sources.

The current interface language is Spanish.

## Example Data Acquisition Workflow

The Revit Add-in supports the BIM-based operation within the broader data acquisition workflow described in the associated scientific article.

A typical use consists of:

1. Downloading the corresponding individual component data sheet template from the Building Legacy platform
2. Loading the template into the Revit Add-in
3. Selecting the corresponding component type and BIM elements
4. Retrieving the available parameter values from the BIM model
5. Transferring the retrieved values to the corresponding fields of the template
6. Complementing the template with information from other available sources where required
7. Uploading the resulting individual component data sheet to the Building Legacy platform

BIM-based extraction and complementary data entry do not constitute a strictly sequential process and may be performed in either order.

## Relationship Between the Research Materials

The materials provided in this repository represent different stages in the derivation and operationalisation of the reusable component data model:

    Candidate parameters
            ↓
    Parameter evaluation and selection
            ↓
    Reusable component data model
            ↓
    Component-specific parameter structures
            ↓
    Individual component data sheet templates
            ↓
    Data acquisition
            ↓
    Component records in Building Legacy

The parameter mapping and component data sheets document the research process through which the reusable component data model was derived and structured. Individual component data sheet templates provide its operational representation for documenting individual reusable components, while the Revit Add-in supports the acquisition of a subset of their parameter values from BIM models.
