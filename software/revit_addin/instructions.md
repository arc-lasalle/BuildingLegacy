# Installation and Usage Instructions

This document describes the installation and use of the Revit Add-in developed within the Building Legacy project to support semi-automated acquisition of reusable component information from BIM models.

The Add-in operates with individual component data sheet templates generated by the Building Legacy platform and transfers parameter values available in a Revit model to the corresponding fields of these templates.

## 1. System Requirements

Before installing the Add-in, ensure that the following requirements are met:

- Autodesk Revit 2026
- Windows operating system
- Compatible .NET environment
- Visual Studio 2022 or later (when compiling from source)

---

## 2. Installation

### Step 1 – Compile the Add-in

1. Open the project or solution file in Visual Studio.
2. Build the project in Debug or Release mode.
3. Locate the generated `BLComponentTemplate.dll` file in the corresponding build output folder.

### Step 2 – Install the Add-in in Revit

1. Copy the generated files to a local folder, for example:

       C:\RevitAddins\BuildingLegacy\

2. Create or edit the corresponding `.addin` file using the following structure:

       <RevitAddIns>
         <AddIn Type="Application">
           <Name>Building Legacy Component Template</Name>
           <Assembly>C:\RevitAddins\BuildingLegacy\BLComponentTemplate.dll</Assembly>
           <AddInId>YOUR-GUID-HERE</AddInId>
           <FullClassName>BLComponentTemplate.RevitApp</FullClassName>
           <VendorId>BL</VendorId>
           <VendorDescription>Building Legacy Project</VendorDescription>
         </AddIn>
       </RevitAddIns>

3. Place the `.addin` file in:

       C:\ProgramData\Autodesk\Revit\Addins\2026\

### Step 3 – Launch Revit

1. Open Autodesk Revit 2026.
2. Locate the Building Legacy command in the Revit ribbon.
3. Launch the Add-in.

---

## 3. Data Acquisition Workflow

### Step 1 – Obtain an Individual Component Data Sheet Template

Individual component data sheet templates are generated by the Building Legacy platform according to the parameter structure defined for each component type.

Download the template corresponding to the component type to be documented.

A representative fire-door template is included in this repository:

    data/templates/Plantilla_puerta_contraincendios.xlsx

The Add-in writes BIM-derived information into this template while preserving previously populated information that is not replaced by the extraction process.

### Step 2 – Select the Component Type

Select the corresponding component type from the Add-in interface.

The current implementation supports the component types addressed in the research:

- Fire doors
- Metal structure pillars
- Glasses
- Tarpaulins
- Rev-A2A heat pumps
- Steel roll-up shutters

### Step 3 – Identify BIM Elements

The Add-in identifies elements in the Revit model corresponding to the selected component type.

Two matching strategies are available:

- **Precise detection:** applies more restrictive identification rules.
- **General detection:** uses broader matching criteria when elements cannot be identified through the precise strategy.

The user can select the BIM elements whose information will be processed.

### Step 4 – Load the Individual Component Data Sheet Template

Load the corresponding `.xlsx` template into the Add-in.

The first worksheet of the Excel file is used. Parameter matching is based on parameter names rather than fixed cell positions.

### Step 5 – Select BIM-derived Information

The Add-in identifies the parameter values that can be obtained from the selected BIM elements.

Depending on the information available in the Revit model and on the component type, these may include:

- Product identification information
- Manufacturer or brand
- Model or reference
- Component dimensions
- Location information
- Material information
- Material surface or volume
- Material thermal conductivity
- Material density
- Number of instances

The availability of these values depends on the information represented in the BIM model.

The user can select which available BIM-derived parameters are to be transferred to the individual component data sheet.

### Step 6 – Export to the Individual Component Data Sheet

The selected BIM-derived values are transferred to the corresponding parameter fields in the Excel template.

Parameter correspondence is established using the parameter names defined in the template. The Add-in updates the corresponding value fields while preserving previously entered information that is not replaced through BIM extraction.

The resulting `.xlsx` file can subsequently be complemented with information obtained from other available sources before being uploaded to the Building Legacy platform.

---

## 4. Data Handling

- Parameter matching between the Add-in and the Excel template is based on parameter names.
- The Add-in uses the first worksheet in the Excel file.
- Parameter names and template structure should not be modified.
- Units are defined in the template and are not modified by the Add-in.
- Multi-value fields use semicolon-separated values.
- Previously populated information is preserved unless the corresponding parameter is selected for BIM-based update.
- BIM-based extraction provides only the subset of reusable-component information represented and retrievable from the Revit model.

---

## 5. Scope and Limitations

The Add-in supports semi-automated information acquisition; it is not intended to automatically document all information required to assess a component for reuse.

BIM models typically contain only a subset of the information required by the reusable component data model. Parameters related to aspects such as component condition, previous use, supporting documentation, or other reuse-specific information may therefore require complementary information sources.

The quality and completeness of BIM-derived values depend on the information contained in the source Revit model.

The current implementation has been developed and tested with Autodesk Revit 2026. The extraction mechanism is therefore specific to the Revit environment. Future implementations could extend the approach to other BIM authoring environments or adopt an openBIM approach based on IFC.

The current interface language is Spanish.

## 6. Troubleshooting

| Issue | Possible cause | Suggested action |
| --- | --- | --- |
| Add-in not visible | Incorrect `.addin` path or configuration | Check the installation folder and `.addin` configuration |
| Component not detected | Identification rules do not match the BIM element | Try the general detection strategy |
| Parameter not extracted | Information is absent or not retrievable from the BIM model | Document the value from another available source |
| Material property unavailable | Corresponding material information is not defined in Revit | Review the material properties in the BIM model |
| Excel export fails | Excel file is locked or unavailable | Close the file and retry the operation |

---

## 7. Relationship with the Building Legacy Workflow

The Revit Add-in implements the BIM-based information acquisition operation within the broader workflow described in the associated scientific study.

Its purpose is to reuse structured information already available in BIM models and transfer it to the individual component data sheet used by Building Legacy. It does not replace complementary data acquisition from technical documentation, inspections, professional assessments, or other available information sources.

Once the individual component data sheet contains the required information, it can be uploaded to Building Legacy to create or update the corresponding component record.
